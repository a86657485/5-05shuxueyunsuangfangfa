## 二、教材目标、重点和本轮难点诊断

教材p31明确给出两项目标，维持现代码G1/G2编码：

- G1：通过对数学运算中求解方法的分析，了解算法在数学解题中的作用，认识算法的顺序结构。
- G2：从算法视角看待计算问题，知道算法是解决问题的方法描述。

蓝栏p31把两项合称“教学重难点”，没有进一步分列重点与难点。保留现代码的K1/K2，不因为本轮支持设计改写教材原文：

- K1：用自然语言描述数学运算中的算法。
- K2：把简单计算题的解题过程，用明确有序的步骤表示（本课使用流程图辅助）。

本轮依据“游戏太难”的课堂反馈，补充的难点诊断（教学分析，非教参原句）：

- D1：把公式看懂并拆成可执行步骤，注意括号和数据依赖；例如要先得到m，才能用它求s。
- D2：区分一次计算的答案与通用方法，能在另一输入下检验方法；签到站还要从给出的数列发现并验证规律。
- 流程图应重点判断每框的操作类型和箭头关系。画图漂亮、记住形状名、点过知识卡都不能单独证明G1/G2达标。

## 五、各站可直接使用的知识卡文案

### temp：先学一学：把计算说清楚

教材书页31；原图：`temp-textbook-p31.png`。

1. 先问自己：要算什么？已经知道什么？准备用哪条规则？
2. 输入是拿到的数，处理是按规则计算，输出是给出的结果。
3. 同一个计算方法，换一个输入也应该能照着做。
4. 温度换算先算括号里的“华氏温度减32”，再把结果乘5、除以9。

**跟着做：把68℉换成摄氏温度（示例数据）**

1. 输入：华氏温度68。
2. 先算括号：68－32＝36。
3. 把36乘5，得到180；再除以9，得到20。
4. 输出：摄氏温度20℃。把方法写成“输入华氏温度→按公式计算→输出摄氏温度”，换数还可以用。

**下一步：** 现在用教材里的50℉自己分析三问、安排计算顺序、写三步方法，再换一个输入检验。

教学提醒：计算顺序可详细示范；目标题候选不预选、不用正确色高亮。

### flow：先学一学：流程图怎样表示步骤

教材书页32；原图：`flow-textbook-p32.png`。

1. 流程图把每一步写进图框，用箭头告诉别人按什么方向做。
2. 圆角矩形表示开始或结束，直角矩形表示计算和处理。
3. 平行四边形表示输入或输出。
4. 顺序结构沿箭头一步一步执行：先拿到数，再计算，最后给结果。

**跟着看：原有4张贴纸，再得到3张（类似问题）**

1. 开始（圆角矩形）。
2. 输入原有贴纸数4（平行四边形）。
3. 计算贴纸总数：4＋3＝7（直角矩形）。
4. 输出总数7（平行四边形），然后结束（圆角矩形）。
5. 用箭头依次连接；若先输出再计算，执行者还拿不到结果。

**下一步：** 现在查看同学的温度流程图，逐框检查“这一步做什么、图框是否合适、顺序是否能执行”，自己找错并修改。

教学提醒：截图是符号和规范图的学习资料，不把目标题各框预标为“应选××”。

### seeds：先学一学：两个结果，按顺序求

教材书页33；原图：`seeds-textbook-p33.png`。

1. n是要分到第几组，也表示一共有多少组；m是第n组的种子数，s是前n组的种子总数。
2. 题目要两个结果：第n组分几粒，以及前n组一共分几粒。
3. 先用n算出m，再把m放进总数公式算s；后一步需要前一步的结果。
4. 可以写成四步：输入n、计算m、计算s、输出m和s。
5. 学习怎样使用公式和安排步骤即可，暂时不需要自己推导总数公式。

**跟着做：先看4组的情况（示例数据）**

1. 输入组数n＝4。
2. 先求第4组：m＝4×2＋1＝9（粒）。
3. 再求总数：s＝4×（3＋9）÷2＝24（粒）。
4. 输出m＝9粒、s＝24粒。用3＋5＋7＋9＝24再检查一次。

**下一步：** 现在保留教材“第1组3粒、第2组5粒、第3组7粒……”的条件，自己求10组的两个结果，再写步骤、检查流程图并换组数验证。

教学提醒：n=4避开主任务n=10及现有换数检验n=6；科学课情境照教材保留，不增加发芽科普。

### signin：先学一学：找规律，还要验证

教材书页34；原图：`signin-textbook-p34.png`。

1. 遇到一串积分，先比较相邻两次：每次增加多少？
2. 再看第1次已经有多少；从第1次到第k次，一共增加了k－1次。
3. 写出规律后，把前几次的数放回去算，看看是否都对得上。
4. 方法卡要写“怎样根据次数求积分”，换一个次数也要能照着算。

**跟着做：另一种奖励规则2、6、10、14……（不同规则示例）**

1. 观察：第一次有2枚，以后每次增加4枚。
2. 求第5次：从第1次到第5次，增加5－1＝4次。
3. 计算：2＋4×4＝18（枚）。这条示例规律也可写成“奖励数＝4×次数－2”。
4. 代回检查：1次得2，2次得6，3次得10，和示例表一致。

**下一步：** 现在回到教材的1、4、7、10……，自己找这条规律并举例验证，再做“签到15次”和“换次数”都能用的方法卡。

教学提醒：先学提供找规律方法，仍不预填本题a、b。若连续卡住可用本题逐步数出增加次数，再由学生完成规律和验证；此后不标为无提示独立迁移。

### formula：选做前看一眼：公式也能写成算法

教材书页34；原图：`formula-textbook-p34.png`。

1. 先选一个自己学过的公式。
2. 写清需要输入哪些数、用什么公式计算、最后输出什么。
3. 同一方法换一组数还能算对，才说明没有把某次答案写死。

**例：求长方形周长，长5米、宽2米（示例数据）**

1. 输入长5和宽2。
2. 先算5＋2＝7，再算7×2＝14。
3. 输出周长14米；方法仍写“（长＋宽）×2”，不要只写14。

**下一步：** 现在自选现有公式任务，写出自己的三步方法并换数验证；可随时退出选做。

## 六、出错后支持和证据判断

1. 操作位置与动作直接说明。使用操作帮助不等同于不理解；未作答选项不用正确色、箭头或默认选择暗示正确项。
2. 首次错误反馈指出具体差异，例如“执行到计算s时还没有m”，避免只说“再想想”。点亮的是需要修改的操作位置，不把某个候选标成答案。
3. 连续出错时按错误类型递进：定位当前一步→用不同数据做一次完整示范→回到当前题给一个局部可执行动作→学生自己完成并重验。允许详细的分步帮助，不把“保留思考空间”理解成一律禁止具体指导。
4. 提示后保留首答与修订记录。原题在帮助后通过说明“能在支持下完成”；随后换输入/换条件再验证，才进一步判断方法是否可以迁移。
5. 签到站新增先学后，现有标签“独立迁移”应调整为“迁移应用”或“方法卡应用”。只在确有无概念提示的变化任务记录时，才把该次表现称为独立迁移。知识卡看过、奖励小游戏通关不补作目标达标证据。
6. 首次进入每站先显示知识卡；完成后进入探究。回看有常驻入口，重入可立即关闭，恢复当前任务与已选内容，不反复强弹或清空。不能用停留倒计时冒充“学会”。
