# 生活算法站 · 五年级第5课《数学运算讲方法》（V2 逆向设计对齐版）

每一项活动都指向教材学习目标与重难点，并留下可查看的理解证据。登录后进入**俯视校园 RPG 小地图**（方向键/WASD 或手机虚拟摇杆走动，靠近站点按空格或点「对话」进入关卡）。主线4站 + 选做 + 20题检测：

| 站 | 证据点 | 指向 |
|---|---|---|
| 气象角（温度换算） | ①问题三问+输入—处理—输出 ②计算顺序会影响结果 ③写三步，请同桌照着做 | G1 G2 / G1 / K1 K2 G2 |
| 教室黑板（流程图） | ①跟老师在学习单上画（自查，不计分） ②帮同学改流程图 | K2 |
| 科学实验室（大豆种子） | ①自己分析 ②先手算、写四步、同桌验证 ③画成流程图 | G1 / K1 K2 G1 / K2 |
| 阅读小站（签到积分，迁移） | ①找规律并举例验证 ②写方法卡 ③出门条 | G1 / K1 K2 G2 / 自知 |
| 公式墙（选做） | 选一个公式写成算法 | 迁移 |
| 课堂检测 | 20题：G1 G2 K1 K2 各5题（题库32题，每题标目标与A/M/T层级） | 全部 |

G1 目标1 顺序结构与算法作用 · G2 目标2 算法是方法描述 · K1 重难点1 自然语言描述 · K2 重难点2 明确有序步骤/流程图

核心机制“同桌照着做”：学生用“做什么 + 对哪个数 + 怎么算”组句写步骤，应用逐字执行并换两组数检验。写死答案、“算一下”、先乘除再减32、先算s再算m、缺输入/输出都会在执行中卡住并指出哪一步。

## 上课
1. 双击 `启动课堂.command`（按脚本所在文件夹运行；会在 /opt/homebrew/bin、/usr/local/bin 中找 Node.js，需 22.13 以上）。
2. 教师大屏：`http://localhost:8795/teacher`（免密码，默认只允许教师电脑本机；讲台平板等需启动前设置 `TEACHER_ALLOW=IP`）。
3. 学生：`http://教师电脑IP:8795/`（窗口里会打印局域网地址）。
4. 教师测试：大屏右上“教师测试”或 `/test`，可看每步参考答案，不写入班级数据。

终端方式：在本文件夹执行 `npm start`。

名单：`roster.json`（501—504，不随示例分发，已 gitignore）。更新：`python3 tools/import-roster.py 五年级班级姓名名单.xlsx`。示例名单 `roster.example.json` 只含虚构姓名。

课堂数据：`runtime/classroom.sqlite`（自动保存；断网时学生端暂存，恢复后补传去重）。新一轮：大屏“开启本班新一轮”（旧轮记录保留）。
