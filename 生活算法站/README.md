# 生活算法站 · 五年级第5课《数学运算讲方法》（V3 先学与分层支持版）

每一项活动都指向教材学习目标与重难点，并留下可查看的理解证据。登录后进入**俯视校园 RPG 小地图**（方向键/WASD 或手机虚拟摇杆走动，靠近站点按空格或点「对话」进入关卡）。主线4站 + 选做 + 基础16题/可选挑战4题：

G1 目标1 顺序结构与算法作用 · G2 目标2 算法是方法描述 · K1 重难点1 自然语言描述 · K2 重难点2 明确有序步骤/流程图

剧情主线为“校园开放日：为友好学校伙伴准备能照着做的校园体验指南”。登录后接到任务，四站分别整理气温介绍、写清流程、安排大豆材料与说明阅读积分规则；各站结算显示指南成果与下一站线索。剧情可跳过，右上角“▤”与关卡“重看任务”可回顾，图片全部本地保存。候选选项只用中性题组提示，检查与下一步按钮仍有明确引导。

核心机制“同桌照着做”：学生用“做什么 + 对哪个数 + 怎么算”组句写步骤，应用逐字执行并换两组数检验。写死答案、“算一下”、先乘除再减32、先算s再算m、缺输入/输出都会在执行中卡住并指出哪一步。

每站先显示教材相关区域、知识要点与不同数据示例；“学习资料”可随时重开，作品保留，查看资料不记通过或积分。有效错误提交连续1/2/3次时，依次给观察点、方法支架、当前一步的具体行动。流程图的任务明确为“3类问题，涉及4个位置”，判定条件保持。

当前四个必做站通过后，服务器自动开放基础检测，选做站不阻挡；开卷后不会因返回改作品而收回。基础达到80%（16题至少13题正确）达标并解锁“算法搭档配对”与原有“算力工厂”；挑战自选且不能补基础分。挑战可跳过，跳过不记0分成绩。教师按班关闭检测。题库保留原32题及历史ID，新增4个排序/配对题；G2-8因表述泛化仅停止新版抽取，不删历史。

课堂学习时间按25—30分钟设计，含剧情、移动、先学和约7分钟基础检测；挑战与奖励只占余时。提示后通过及程序换数执行能证明支持下的方法可执行，不能单凭通关或得分推断独立生成算法、主动选择反例或独立迁移。真实学生完成率和用时仍待课堂验证。

## 上课
1. 双击 `启动课堂.command`（按脚本所在文件夹运行；会在 /opt/homebrew/bin、/usr/local/bin 中找 Node.js，需 22.13 以上）。
2. 教师大屏：`http://localhost:8795/teacher`（免密码，默认只允许教师电脑本机；讲台平板等需启动前设置 `TEACHER_ALLOW=IP`）。
3. 学生：`http://教师电脑IP:8795/`（窗口里会打印局域网地址）。
4. 教师测试：大屏右上“教师测试”或 `/test`，可看每步参考答案，不写入班级数据；`/demo` 同属教师设备预览入口。

终端方式：在本文件夹执行 `npm start`。可用 `PORT` 指定端口、`DATA_DIR` 指定独立数据目录；同一课堂所有学生使用教师电脑当前IP对应的同源地址。正式学生入口为 `/`，无需给学生使用localhost。

名单：`roster.json`（501—504，不随示例分发，已 gitignore）。更新：`python3 tools/import-roster.py 五年级班级姓名名单.xlsx`。示例名单 `roster.example.json` 只含虚构姓名。

课堂数据：`runtime/classroom.sqlite`（自动保存；断网时学生端暂存，恢复后按身份和轮次依序补传去重，再保存新作答）。新一轮：大屏“开启本班新一轮”（旧轮记录保留）。不跨课补做旧轮未完成任务或检测；下次上课由教师开启新轮，旧记录保留供回看。
